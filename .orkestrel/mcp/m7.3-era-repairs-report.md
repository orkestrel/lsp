### Correlated adapter failures and growth bound

Discovery before handshake completion and malformed translated results now emit the existing
`error` event and a correlated JSON-RPC error response. Correlation entries are removed on a valid
result, peer error result, malformed result, carrier send rejection, adapter timeout, or close.
A forwarded request that receives no response gets a correlated `-32603` timeout response.

The map retains at most one entry per distinct unanswered correlated request for no longer than the
configured adapter timeout, unless `close()` removes it earlier. Reusing an id replaces its entry.
No request that has settled through an adapter-owned door remains in the map. This required no
public type change.

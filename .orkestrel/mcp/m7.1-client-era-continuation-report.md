## Owned-row migration

The M7 report rulings were applied as follows:

| Former `MCPClient` row | Result |
| --- | --- |
| `keeps a pinned legacy handshake unchanged, including its initialized notification` | Moved and renamed `keeps the adapter pin on the legacy handshake and exposes the modern revision`. |
| `rejects an unsupported legacy protocol, closes, and sends no initialized notification` | Moved and renamed `rejects an unsupported negotiated legacy revision before initialization completes`. |
| `rejects a pinned legacy reply that negotiates a different supported revision` | Moved and renamed `rejects a negotiated revision that differs from the adapter pin`. |
| `rejects an absent legacy protocol and closes before initialization completes` | Moved and renamed `rejects an absent legacy protocol before initialization completes`. |
| `rejects a malformed legacy protocol and closes before initialization completes` | Moved and renamed `rejects a malformed legacy protocol before initialization completes`. |
| `accepts a legacy result with no resultType` | Replaced in the bare-client suite by `refuses a legacy result on the bare transport and names the adapter`. Adapter result restoration remains proved by the `tools/list` and `tools/call` conversion rows. |
| `leaves the client disconnected when the initialized notification fails to send` | Moved and renamed `leaves the client disconnected when the adapter initialized notification fails`. |
| `rejects a superseded legacy connect when disconnect lands during the initialized notification` | Moved and renamed `rejects a superseded connect after the adapter initialized notification lands`. |
| `rejects a superseded legacy connect when disconnect lands during the initialize round trip` | Reworked as `completes the adapter-owned handshake before closing a superseded connect`. |
| `leaves a live session untouched when a superseded attempt finally unwinds` | Reworked as `waits for the superseded adapter handshake before opening the next connection`. |
| `settles a superseded attempt whose wire write never lands, then admits the next connect` | Reworked as `bounds an adapter handshake write that never lands and admits the next connect`. The adapter bounds handshake writes with its configured deadline. |
| `still surfaces a failing initialized notification on a reconnect after a disconnect` | Moved and renamed `surfaces a failing adapter initialized notification on reconnect`. |
| `waits for its own handshake write on a reconnect after an earlier disconnect` | Moved and renamed `waits for the adapter handshake write on reconnect`. |
| `CONTROL — a legacy initialize result legitimately carries none and still connects` | Moved with its marking as `CONTROL — accepts the unstamped legacy handshake result through the adapter`. |

The additional stale row `caches a legacy era across disconnect and reconnect without probing modern again` became `repeats the adapter handshake across reconnect without peer discovery`. The adapter, rather than the bare client, now owns each legacy handshake.

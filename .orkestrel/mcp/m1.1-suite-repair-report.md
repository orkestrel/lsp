## What changed per file

- `src/server/inferers.ts` — `inferLegacyVersion` reads `isMCPLegacyVersion(requested)` directly,
  the same read `buildInitializeResult` performs, and returns the narrowed `MCPLegacyVersion`.
  Dropped the now-unused `inferEra` and `inferVersion` imports; the `@remarks` records why the
  modern-only inferer cannot serve this path.
- `tests/src/server/handlers.test.ts` — modern fixtures restamped `MCP_MODERN_VERSION`, `-32022`
  data made modern-only, two arrival-only cases given substance assertions, unused
  `MCP_PROTOCOL_VERSION` import removed.
- `tests/src/server/factories.test.ts` — `server/discover` canary in the routes and stdio cases,
  modern-only `-32022` data, and the era case extended to prove the bare-refuses/decorated-serves
  split its name claims.
- `tests/src/server/transports/WebSocketClientTransport.test.ts` — `server/discover` canary with
  the full discover result pinned; imports `DEFAULT_MCP_CACHE_TTL` and `MCP_MODERN_VERSION`.
- `tests/src/browser/helpers.test.ts` — every canary swapped to `server/discover`;
  `expectModernReply` asserts the discover payload.
- `tests/src/browser/factories.test.ts` — SSE second leg drives `server/discover`.
- `guides/mcp.md` — added `isMCPModernVersion` and `isMCPLegacyVersion` to the era fence with
  their disjointness (see the deviation note).

## Deviations

One, carried rather than stopped, because it sits inside the stated objective and inside a granted
file.

- **Expected:** the enumerated failing set was the whole red surface.
- **Found:** `tests/guides.test.ts > MCP > documents an example for every Surface function` failed
  with `[ 'isMCPModernVersion', 'isMCPLegacyVersion' ]`, symbols M1 added to the guide's Surface
  table with no `@example`.
- **Evidence:** the baseline log's chain is `test:src && test:policy && … && test:guides && …`,
  and it records only `test:src`. `test:src` failing aborted the chain, so `policy`, `config`,
  `setup`, `guides`, `conformance`, and `integration` never ran in the baseline. This failure is
  pre-existing M1 drift the enumerated set could not have seen, not a regression from this unit.
- **Done:** closed in `guides/mcp.md` — the file the brief's Scope grants — by adding both guards
  to the existing era fence with their assertions. The alternative home was a TSDoc `@example` in
  `src/core/validators.ts`, which the brief puts off-limits.
- **Hypothesis:** the brief's failing set was derived from a run that stopped at the first failing
  project, so any cross-cutting project's state was unmeasured at dispatch.

Ancillary decisions recorded: `server/discover` as the replacement canary throughout; the
`ping` payloads in `WebSocketClientTransport.test.ts` that assert only `send` resolution or
rejection are left as they are, because they never read a server reply and the method's removal
does not make them false.

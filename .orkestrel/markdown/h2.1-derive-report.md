## Derivation rule

For each output node, `Markdown.#derive` reads the node's own span from the source handle first. If
that span is absent, it reads only the direct input named by the current rewrite and uses that
input's span from the source handle. It does not follow the input identity's derivation entry from
the same rewrite.

The source handle has already resolved every earlier map into its span map. A further edge in the
current rewrite describes the input identity's separate role as an output elsewhere, not another
source for the subject node. Stopping at the direct input preserves the source-first identity rule,
terminates for every map shape, keeps a legitimate one-source span, and returns `undefined` when
the direct input has no span.

In the public `T -> S -> C` construction, `T` reads no span from `S` and returns `undefined`.
The separately emitted `S` remains a direct replacement for `C` and receives `{ start: 6, end: 7 }`.

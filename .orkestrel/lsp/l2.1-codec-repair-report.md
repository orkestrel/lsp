### Decode state and header limit

`LSPDecodeState` is an unresolved/resolved union. Each node contains the newest `bytes` segment, an optional `previous` node, and cumulative `size`. Resolved nodes also contain paired numeric `boundary` and `length` members.

A continuation appends one node. Header search examines the added bytes with at most the preceding three bytes. After header resolution, later chunks retain `boundary` and `length`, bypass header scanning, and flatten the retained segments only when the frame completes. Work therefore grows linearly with delivered bytes.

`LSP_HEADER_LIMIT` is `65_536` bytes (64 KiB). It admits extension fields while bounding boundary-free header accumulation. `LSP_CONTENT_LIMIT` remains `67_108_864`.

## Findings outside the claims

**A. `#begin` writes `initialize` onto a transport generation it no longer owns, because the only unguarded shared write sits between the transport start and the handshake request.** `src/core/LSPClient.ts:211` awaits `this.#transport.start()`, and the next shared write is `await this.#request(LSP_METHODS.initialize, params)` at `:235` with no `#ownsGeneration` call between them — unlike `:247` and `:250`, which guard every later write. `#send` then permits it, because its predicate reads the phase alone (`:385-392`) and never the generation.

The interleaving: `client.start()` mints generation 1 and suspends at `:211`; the transport emits `exit` while its own `start()` promise is still pending; `#receiveExit` (`:570-580`) writes `closed`, clears the session, drains nothing because no request has been registered yet, and emits `exit`; a handler calling `client.start()` — the pattern `tests/src/core/LSPClient.test.ts:1186` establishes as supported — mints generation 2 and takes `starting`; generation 1's `transport.start()` then resolves and writes its `initialize` onto the connection generation 2 owns. Two `initialize` requests reach one connection, which the base protocol forbids, and the second symptom is quieter: generation 1's `start()` promise never settles at the exit, because `#drain` found nothing pending.

Why it matters: this is the class the repair exists to close, reached through the only door the generation identity does not cover. It is reachable through `LSPTransportInterface`, a documented extension seam whose TSDoc (`src/core/types.ts:211-218`) constrains when the *client* may call `start` again and says nothing about the transport emitting `exit` before its own `start` settles — an ordinary outcome for a process that dies during spawn. `.claude/rules/quality.md` § Rounds and verdicts requires a seam's ruling to name the interface where a consumer meets the obligation; this one names the invariant and the constraint but not that interface.

What right looks like: one line, matching the two the fix already added — after `:211`, `if (!this.#ownsGeneration(generation)) throw new LSPError('The LSP transport is closed', { code: 'closed' })`. It closes the stray write and settles the orphaned `start()` promise coded `closed` in the same stroke. If the Orchestrator rules the ordering out of contract instead, the obligation belongs on `LSPTransportInterface`'s `@remarks`.
